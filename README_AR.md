# NOVA AI STUDIO — النسخة الأولية

هذه نسخة واجهة أمامية تجريبية متجاوبة للموبايل والكمبيوتر، مستوحاة من أسلوب استوديوهات الذكاء الاصطناعي.

## التشغيل
- فك ضغط الملف.
- افتح `index.html` في المتصفح لمعاينة الواجهة.
- لتجربة التثبيت كتطبيق PWA والعمل دون اتصال، شغّل المجلد من خلال خادم محلي أو استضافة HTTPS.

## الموجود حاليًا
- واجهة عربية RTL بتصميم داكن.
- التبديل بين توليد الصور، نص إلى فيديو، وتحريك صورة.
- إدخال وصف نصي ورفع صورة ومعاينتها.
- تصميم متجاوب للموبايل والكمبيوتر.
- صفحة مكتبة أولية.

## غير الموجود بعد
التوليد الحقيقي للصور والفيديو غير موصول في هذه النسخة. زر «تجهيز الطلب» يتحقق من المدخلات فقط ولا يدّعي إنشاء صورة أو فيديو.

## الخطوة التالية
اختيار محرك توليد مناسب وربطه بخادم آمن. لا تضع مفاتيح API داخل ملفات الواجهة أو JavaScript الذي يصل للمتصفح. سنحتاج:
1. Backend لإدارة الطلبات ومفاتيح الخدمات.
2. محرك صور مفتوح المصدر أو خدمة مجانية بحدود استخدام.
3. محرك فيديو مناسب للموارد المتاحة، أو مزود API بخطة مجانية إن توفرت.
4. نظام حسابات وتخزين اختياري عند الحاجة.

## ملاحظة الخصوصية
الملفات المرفوعة في هذه النسخة تتم معاينتها محليًا في المتصفح، ولا يتم إرسالها إلى خادم.
